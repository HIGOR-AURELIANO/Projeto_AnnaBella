# Palette Journal - Anna Bella Oficial

This journal documents critical UX and accessibility learnings for the Anna Bella Oficial project.

## 2025-05-15 - Initializing Palette Journal
**Learning:** The project is a static multi-page site without a templating system, requiring manual synchronization of common components like the navigation menu across all HTML files.
**Action:** Use `grep` or careful manual updates to ensure structural parity across all `.html` files when modifying shared components.
