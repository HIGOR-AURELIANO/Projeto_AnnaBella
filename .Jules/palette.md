## 2024-05-24 - [Semantic Navigation and Responsive Layouts]
**Learning:** Using semantic HTML like `<nav>` and standard accessibility attributes like `aria-current="page"` significantly improves screen reader navigation and provides clear visual/structural context for all users. Combining this with fluid layouts (`max-width` and percentage widths) ensures a consistent experience across different device sizes.
**Action:** Always prefer semantic elements and standard ARIA attributes for core UI components and ensure the layout is responsive from the start.
