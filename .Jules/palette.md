## 2025-05-14 - Semantic Navigation and Focus Visibility
**Learning:** Using generic `div` IDs for layout components (header, nav, main, footer) is common in older static sites but hinders screen reader navigation. Additionally, default focus states are often overlooked in minimalist designs, making them inaccessible to keyboard users.
**Action:** Always replace generic layout containers with semantic HTML5 tags and implement explicit `:focus-visible` styles to ensure accessibility without affecting mouse users' visual experience.
