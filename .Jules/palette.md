## 2025-05-15 - Enhancing Static Navigation and Keyboard Accessibility
**Learning:** In a static site without a templating system, maintaining consistent navigation feedback (visual and semantic) requires manual synchronization across all HTML files. Standardizing accessibility features like `focus-visible` and `aria-current` significantly improves the experience for keyboard and screen reader users with minimal code footprint.
**Action:** When working on static sites, audit all pages for navigation consistency and ensure focus indicators are present and distinguishable from hover states.
