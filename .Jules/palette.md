## 2025-05-26 - [Responsive & Accessible Navigation for Static Sites]
**Learning:** In pure static HTML/CSS projects without templating engines (like Jekyll or React), micro-UX enhancements to global components like navigation or headers require manual synchronization across all pages. This increases the risk of inconsistent states (e.g., active menu links) if not systematically verified. Additionally, `:focus-visible` is essential for modern accessibility but often overlooked in older-style static layouts.
**Action:** When working with multi-page static HTML sites, always use a script (like Playwright) to verify that global UX enhancements are consistently applied to every entry point. Implement a standard focus-ring style to ensure keyboard accessibility across all interactive elements.
